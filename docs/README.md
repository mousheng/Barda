## Barda

**Barda** 继承自 **Openblocks** 项目，而 **Openblocks** 则是国内低代码平台**码匠**的开源版本。

Barda 是一款开发者友好的低代码平台。通过开箱即用的组件库、所见即所得的 UI 布局以及便捷的数据库/API 连接，您可以快速开发内部应用，同时无需关注复杂繁琐的前后端交互、应用的安装与部署，让您专注于业务发展。

## 如何搭建应用？

只需通过几个简单步骤，便可快速搭建和使用您的内部应用：

1. **连接数据源**：通过 GUI 快速[连接数据源](datasource.md)
2. **构建查询**：编写少量代码[构建查询](how-to-write-query.md)
3. **设计界面**：使用开箱即用的组件库轻松[搭建应用界面](drag-and-drop.md)，使用 [JavaScript 表达式](javascript-in-barda/writing-javascript.md)绑定查询数据
4. **设置交互**：通过设置[事件触发](event-handler.md)实现查询触发、组件控制和用户行为响应，提供响应式 UI 交互
5. **发布分享**：[预览](app-release.md)并将您的应用分享给其他人
