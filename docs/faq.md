## 是否可以开发复杂的系统应用？

Barda不但可以基于数据库和 API 快速创建企业内部的轻量级应用，还支持企业搭建个性化的中大型系统，如 ERP、MES、CRM 等系统。

## 为什么我在Barda只能搭建单个页面的应用？

您的单页面应用可通过Barda的[聚合页](left-navigation.md)功能，组合成侧边栏等形式，以形成复杂、完整的应用系统。具体功能，可根据相关文档轻松实现。


## 搭建完成的应用如何部署？

Barda可以实现开发即部署，省去部署环节。搭建完应用之后，可以直接分享使用，Barda系统会处理好应用部署、身份认证、权限管理、记录操作日志等工作。

## 是否支持私有化部署？

为确保数据安全，Barda支持用户进行[私有化部署](docker.md)，部署方式为通过 Docker 镜像实现，支持客户随时对Barda的最新版本进行升级。

## 如果我有非常个性化的开发需求怎么办？

Barda具有强大的拓展性和自定义功能，组件属性中几乎任何地方都支持通过代码进行灵活、动态的设置。另外，系统支持用户独立开发 npm 插件、支持添加 JavaScript 库和 CSS 自定义样式，全方位满足用户的个性化需求。
